.. _devices:

Supported boards and devices
============================

MicroPython runs on a range of different microcontrollers, devices, and
operating systems. Information about the various ports can be found below, and
a full list of supported boards and pre-compiled firmware can be found at the
`MicroPython downloads page <https://micropython.org/download/>`_.

For information about how to port MicroPython to a new microcontroller or
microcontroller family, see the :ref:`porting guide <guides_porting>`. To add
support for a new board for an existing microcontroller, see the
:ref:`board creation guide <guides_porting_board>`.
