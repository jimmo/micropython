:mod:`_thread` -- multithreading support
========================================

.. module:: _thread
    :synopsis: multithreading support

|see_cpython_module| :mod:`python:_thread`.

This module implements multithreading support.

Threading is available on the :ref:`devices_esp32` and :ref:`devices_rp2` ports,
and selectively on certain :ref:`devices_stm32` and :ref:`devices_pyboard`
builds.

This module is highly experimental and its API is not yet fully settled
and not yet described in this documentation.
